# Hub BI — Landing Page

Site responsivo de captação de leads da Hub BI. A solução é apresentada como inteligência empresarial com dashboards próprios, relatórios gerenciais e assessoria.

## Publicar

Site estático: `index.html` + pasta `css/`, `js/` e `assets/`. Não requer build ou instalação. Para testar localmente, rode `python3 -m http.server 8080` e abra http://localhost:8080. Para Vercel, importe o repositório e use o preset Other sem build.

## Principais recursos

- Hero escuro, arte 3D sem distorções, marca monocromática e faixa infinita de benefícios.
- Mapa de conexões interativo com seis segmentos e indicadores por tipo de negócio.
- Formulário de contato com validação e consentimento. Abre o WhatsApp no número (61) 99370-2380 com as respostas pré-preenchidas, **mas requer confirmação de envio pelo visitante**.
- Chat flutuante com quatro perguntas rápidas e direcionamento ao WhatsApp. Não há IA conversacional, bot conectado à API WhatsApp ou envio automático.
- Imagens originais fornecidas para a LP, com WebP otimizado e SVG nítido.

## Transparência

Os dados do dashboard são ilustrativos. Resultados de economia dependem do cenário de cada empresa. Defina os aspectos de privacidade e identificação jurídica antes de divulgar a página.
